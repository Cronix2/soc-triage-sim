SOC // TRIAGE

Entraînement au tri d'alertes de sécurité. Données entièrement fictives, aucune connexion réseau, aucun compte requis.

Configuration de la session

  • Alertes fictives générées aléatoirement, 7 catégories couvertes
  • Fiche de triage Markdown générée après chaque décision
  • Correction détaillée et note sur 20 en fin de session
